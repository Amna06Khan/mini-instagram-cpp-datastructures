# 📖 Overview

**Mini Instagram** is a console-based social media application developed in **C++** as part of a **Data Structures** course project.

The application simulates the core features of a social networking platform, allowing users to create accounts, publish posts, interact with other users, and manage friendships. It demonstrates the practical implementation of **Data Structures**, **Object-Oriented Programming**, and **File Handling** within a single, well-organized source file.

---

# ✨ Features

- 👤 User Registration & Login
- 📝 Create and Manage Posts
- ❤️ Like Posts
- 💬 Comment on Posts
- 👥 Friend Management
- 🔍 Search Users
- 📰 View News Feed
- 💾 File Handling for Data Persistence
- ⚡ Efficient Data Structure Implementation

# 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Amna06Khan/mini-instagram-cpp-datastructures.git
```

### Navigate to the Project

```bash
cd mini-instagram-cpp-datastructures
```

### Compile

```bash
g++ mini_instagram.cpp -o MiniInstagram
```

### Run

**Windows**

```bash
MiniInstagram.exe
```

**Linux / macOS**

```bash
./MiniInstagram
```
